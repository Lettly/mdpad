# mdpad examples

One file per category of content. Open any of them from the file tree, or follow a link — the
editor renders them the way GitHub does, and every file is meant to be edited.

| File | What it shows |
| --- | --- |
| [text.md](./text.md) | headings, emphasis, links, escapes, line breaks, unicode, inline HTML |
| [lists.md](./lists.md) | bullets, ordered and nested lists, task lists, mixed content in items |
| [tables.md](./tables.md) | alignment, inline formatting in cells, wide tables |
| [code.md](./code.md) | inline code, fenced blocks with and without a language, code in quotes and lists |
| [math.md](./math.md) | inline and display maths, matrices, aligned equations, cases |
| [callouts.md](./callouts.md) | the five GitHub alert kinds, with rich content inside |
| [details.md](./details.md) | collapsible sections, including summaries with formatting |
| [footnotes.md](./footnotes.md) | references, named footnotes, multi-paragraph definitions |
| [html.md](./html.md) | raw HTML blocks, inline tags, `<kbd>`, `<mark>`, HTML tables |
| [quotes.md](./quotes.md) | quotes, nesting, quotes holding other blocks |
| [links.md](./links.md) | inline, reference, autolinks, anchors, relative links |
| [images.md](./images.md) | images, titles, linked images, images inside blocks |
| [diagrams.md](./diagrams.md) | Mermaid flowcharts, sequences, classes, states, gantt |
| [frontmatter.md](./frontmatter.md) | YAML front matter above the document |
| [example.md](./example.md) | a short tour that touches everything at once |

## Editing tips

- Type `/` at the end of a line to open the block menu.
- Select text to get the formatting menu above it.
- `⌘S` / `Ctrl+S` opens the commit dialog.
- **Raw Markdown** switches to the source and back.
